לאחות צעירה
	








החושך מכביד ומגביר את החשד, / העין פקוחה ועוקבת
סביב… / דומה: ועוד קט וקריאה מיואשת – / את חלל העולם כטבעת
תקיף!



גניחה עמומה, אנחה מקוטעת, / ומלל עקר משתפכים בחלל! /
נראית החשכה כזקנה הקולעת / חבל תליה לפושע אומלל!



אין כוח לצעוק והראש מסתחרר, / קדחת בוערת, לוהטת
ביקוד! / מי בפנה הרחוקה מסתתר? / מי מערער בביתי את היסוד?



קשה המטה, היא כאבן בזלת! / כבדה השמיכה ולוחצת כהר! /
מי זה יתן לי סוכה ומחצלת / בחורש של אורן ליד הנהר?



רטבה המיטה מזיעה הניגרת, / היד תלויה וירדה ברפיון! /
דמויות בלהה ואימה מתגברת, / פרי רוח חולה מופיעות בדמיון!



ופתע תנח על הראש הקודח, / יד אם מלטפת, סועדת בדווי! /
כאילו ליטף האביב הפורח, / כאילו נשק לי הפרח החי!



ודמות צחורה ושופעת הזוהר / ניצבת דומם וקורנת בהוד! /
כסמל לחסד האל ולטוהר, / כצרי מחיה ומרפא לבבות!



הגידי אחות לי, אמרי לי מניין: / דלית את הטוב והאור
שנגנז? / והלא את עצמך, את תינוקת עדיין, / ואיך זה גילה לך האל את
הרז?



חכי לי עוד קט, ארדם ואישן, / ותהי לי ידך לעזרה ומגן!
/ ויהי חיוכך לי כפרח הגן, / וברק זיו עינך לי כאבן החן!



ועוד משאלה לי גדולה ונסתרת: / עם בוקר, השחר לאט כי
יפציע… / דמותך הקורנת בהוד ותפארת, / לנגד עיני ראשונה כי תופיע!
