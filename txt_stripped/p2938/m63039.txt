מן העבר
	








לא צעיר אני אביכם, / שבע הרוגז, כפוף הגב. / בנדודים
עייפה הנפש, / למנוחה מעט אשאף!



הזכרת הבת מקדם: / ושיער ראשי שחור? / ועתה נוצץ ככסף,
/ וכשלג הצחור!



וברק עיני זו הדועכת, / הזכרת בה את היקוד? / וקולי עם
צליל מתכת? / הוא אבד, איננו עוד!



התזכרי את הקסם / השופע, המבורך? / בו בנינו את ביתנו /
בו חיברנו הנדבך?



והצחוק שעל שפתיים, / והלב תמים ורך? / ולטיפת היד
בעדן, / ודיבור שקט ורך!



וכוון החן בנועם, / ונשיקה קטנה ביד! / למבט במלוא החסד
/ לבבי תמיד רעד!



מי אשם בנשוא הרוח / את הקסם, העמל? / מי ציוה לי את
הפגע, / מי עשני לאומלל?



מי הרס יסוד הבית, / מי העיז לסתור הקיר? / הכבוד
והתפארת / בחיי חרפה המיר?



בנדודים כלה הכוח, / בדרכים הנשמות! / שם דעכה השלהבת,
/ שם הלבינו שערות!



לא אהיה כפוף כעבד, / אין לי צורך בחסות! / אם לחיות לי
לא נתתם, / תנו לי לפחות למות!
